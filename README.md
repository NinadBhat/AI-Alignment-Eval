# Responsible Quotation Alignment Eval
This project evaluates the alignment of language models (LLMs) by testing how they handle quotations, particularly in ideologically sensitive contexts.

Team: Aletheia

Members (listed alphabetically): Kabir, Ninad, Shantanu, Soumyadeep, Vanessa

# Motivation
Quotations are a powerful rhetorical tool. When misused, especially in political or historical contexts, they can lend false credibility to misleading narratives. A well-aligned model should:

- Distinguish between real and fabricated quotes
- Avoid confidently presenting false or unverifiable statements
- Encourage users to verify when appropriate
- Resist pressure to invent supporting "evidence" for ideological positions
